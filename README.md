# Abdelhamid Boukhris — Portfolio

Minimalist, responsive portfolio website built with separate HTML, CSS, and JavaScript files. No build tools or external libraries required.

## Files
- `index.html` — page content and metadata
- `styles.css` — layout, colors, typography, responsive design
- `script.js` — mobile navigation and project filters

## Preview locally
Keep all three files in the same folder, then open `index.html` in your browser.

## Publish free with GitHub Pages
1. Create a repository named `Hamid101101.github.io` (or use another repository and configure its Pages settings).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save if these options appear.
5. After publication, the site should be available at `https://Hamid101101.github.io/`.
